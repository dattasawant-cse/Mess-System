# Mess-System
Technologies: HTML, CSS, JavaScript, LocalStorage
* Developed a web-based system to manage mess customers and payment records.
* Implemented customer addition, editing, deletion, payment status and
  due-date management.
* Added automatic identification of overdue payments and remaining fees.
* Implemented search and customer filtering functionality.
* Used JavaScript and LocalStorage for client-side data management.
* Created an interactive dashboard displaying customer and payment statistics.
